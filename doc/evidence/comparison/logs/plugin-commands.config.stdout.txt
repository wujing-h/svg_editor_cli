svg-editor 0.1 - type 'help' for commands
init [w] [h]                                       create a canvas (default 800x600)
canvas [w] [h]                                     show or resize the current canvas
save [file.svg]                                    save to a given or previously associated path
read <file.svg>                                    load SVG and assign IDs to unnamed shapes
create <type> <id> [params...] [in <containerId>]  create rect/circle/ellipse/line/text/g
move <id> <dx> <dy>                                move a shape or all descendants of a group
scale <id> <factor>                                scale all geometry by a positive factor
delete <id>                                        delete a shape and all its descendants
set <id> <attr> <value>                            set a supported geometry, style, or text property
addto <gid> <id>                                   move a shape into a container as its last child
front <id>                                         bring a shape to the front among its siblings
back <id>                                          send a shape to the back among its siblings
group <newGid> <id1> [id2...]                      group existing shapes in their original tree order
ungroup <gid>                                      replace a non-top-level group with its children
tree [id]                                          show the document tree or a selected subtree
show <id>                                          show a shape's attributes and parent
undo                                               undo the last edit
redo                                               redo the last undone edit
help                                               show available commands
stats                                              count leaf shapes by type and containers in depth-first order
dir                                                list direct entries in the current working directory
